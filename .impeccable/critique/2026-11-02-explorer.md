# Explorer usability critique

Method: dual-agent (A: ux_critique_a · B: ux_critique_b). Baseline: origin/main at 1e29ada. Target: apps/web/src/App.tsx and associated graph, panels, history and styles.

## Design specificity

The luminous repository graph, morphing layout, developer typography and history are authored for this product. The issue is operational: surrounding controls dominate the artifact, and the interaction path does not fulfill the visual promise.

## What works

- Consistent module colors and several orientation paths.
- Honest demo and CI provenance.
- A restrained frame that can support a compelling central graph.

## Priorities and independent evidence

1. **P1 — Direct exploration.** A reproduced graph-label selection being cleared; B found five of six projected canvas clicks correct and one depth-overlap ambiguity. Zoom works but requires many wheel events (B measured 22.02 to 11.90 after twelve gestures), and the current function scope can reveal no details after selecting a package. Repair event ownership and practical hit targets; provide explicit zoom/Fit and a detail indicator.
2. **P1 — Control and reversibility.** B confirmed all three secondary overlays lacked dismissal and survived Escape. Inspector close retained a 269px desktop column. Fullscreen and History/CI collapse were absent. Use true closeable workspaces and independent panel toggles.
3. **P1 — Tablet adaptation.** B measured 12–14px navigation-button heights, 28px graph tools and clipped outer file centers on portrait. A found later pipeline stages clipped. Use touch-sized targets, adaptive drawers, complete scrollable pipeline layouts and explicit touch gestures.
4. **P1 — Progressive history.** The existing cache is real but short-lived (five minutes, twelve entries), not evidence that every click always downloads. There is no adjacent-commit preparation or visible cache readiness. Add immediate session reuse, longer immutable-SHA persistence and paced, cancellable neighbor warming with a network budget.
5. **P2 — Reduce duplication.** Default overview competes with exploration. Keep Inspector closed until requested or selected, and collapse CI into an optional surface.

## Persona risks

Developer: graph selection and Escape differ from familiar behavior. Tablet user: tiny targets, limited framing and no direct zoom controls. Keyboard/low-vision user: details need equivalent Files/search/list paths and visible focus.
