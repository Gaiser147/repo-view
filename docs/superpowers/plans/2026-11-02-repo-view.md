# repo-view implementation plan

Goal: implement the approved Morph design with local focus, history, real public-repository analysis, pipelines and health. Source of truth: the sibling specs/2026-11-02-repo-view-design.md and the approved conversation plan.

Architecture: React/TypeScript/Vite; Three.js via React Three Fiber; Node 24/Fastify analysis service; shared contracts; SQLite cache; isolated analysis and layout workers.

1. Demo shell: deterministic 50-commit data, navigation, tree, search and Inspector. Verify shared selections and demo labeling.
2. Spatial graph: deterministic volume layout and layer targets, reversible interpolation, stable IDs and semantic zoom. Verify identity, endpoints and axis decorrelation.
3. Focus and craft: locally unfold a group, signal paths, bloom, atmospheric material, responsive panels and accessibility. Verify desktop/mobile and reduced motion.
4. Real analysis: bounded public Git fetch, TypeScript symbol-based calls, import cycles, manifests/lockfiles, workflows, jobs and SQLite. Verify fixtures, empty repositories, limits and worker messaging.
5. History: atomic snapshot replacement, diff and rename detection, playback and older commit pages. Verify stale response rejection and initial branch history.
6. Pipelines/health: DAG and step inspector, actual run matching and versioned rules. Verify unavailable sources remain unassessed.
7. Integration: typecheck, unit/integration tests, production build, browser suite, 5,000-file benchmark, CI, documentation and fresh review.

Review focus: bounded analysis rather than execution; source and demo distinction; stable node identities; unavailable data truthfulness; keyboard/mobile fallback.
